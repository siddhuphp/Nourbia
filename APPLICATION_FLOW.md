## 1. Project Overview & Technology Stack

### 1.1 Brand Vision & Positioning
**Nourbia Foods Inc.** is building a modern, clean, culturally relevant, mobile-first e-commerce experience modeled after **Harvest Right**'s clean commercial presentation. The platform is designed to make culturally familiar, nutritious, convenient, and shelf-stable foods accessible to customers throughout the 50 United States and scalable internationally.

- **Core Positioning**:
  - *"Advancing Culturally Relevant Nutrition"*
  - *"Meeting People Where They Are"*
- **Core Methodology**: **Prove $\longrightarrow$ Build $\longrightarrow$ Scale**
- **Customer Journey**: **Taste $\longrightarrow$ Test $\longrightarrow$ Share $\longrightarrow$ Recommend $\longrightarrow$ Shape**

### 1.2 Technology Foundation (100% Custom / No Shopify)
- **Frontend**: Next.js 15 (App Router, React Server Components, TypeScript, Modular CSS)
- **Backend / APIs**: Python FastAPI (Async, Pydantic v2, SQLAlchemy 2.0)
- **Database**: PostgreSQL 16 (Relational Schema for Products, Variants, Orders, Boxes, B2B Leads)
- **Cache & Performance**: Redis (Session storage, catalog edge caching, rate limiting)
- **Payment Processing**: Stripe Elements (Credit/Debit Cards, Apple Pay, Google Pay)
- **Fulfillment & Shipping**: Multi-carrier API integration (ShipStation, USPS, UPS, FedEx)
- **Asset Supply Notice**: All branding, packaging designs, and product/lifestyle photographs are client-supplied by Nourbia Foods.
